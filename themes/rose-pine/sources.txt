## Backgrounds (default rule as in Omarchy)

Omarchy selects the first of the sorted `backgrounds/` on theme change (`bin/omarchy-theme-set`):
Default = **`1-funky-shapes.webp`**. All four files are located under `backgrounds/` (as of 2026-09-07).
The project is now generic: `rosepine-gnome set <theme>` applies any
Omarchy theme (themes/<id>/colors.toml + optional vscode.json/icons.theme/
backgrounds) on the fly. More themes: copy raw.githubusercontent.com/
omacom/omarchy/quattro/themes/<name>/ … into themes/<name>/.
